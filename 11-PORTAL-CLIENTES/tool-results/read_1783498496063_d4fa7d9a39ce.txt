  1189→  1189→## 1. Procesos en segundo plano (Background Jobs)
  1190→  1190→
  1191→  1191→Supabase ofrece dos caminos limpios:
  1192→  1192→
  1193→  1193→- **pg_cron** (extensión de PostgreSQL) → Ideal para tareas recurrentes simples (cada minuto, hora, día).
  1194→  1194→- **Edge Functions programadas** → Más potentes, con lógica compleja y llamadas externas.
  1195→  1195→
  1196→  1196→### 1.1 Actualización automática de facturas vencidas
  1197→  1197→
  1198→  1198→Queremos que las facturas con `status != 'Paid'` y `due_date < today()` pasen automáticamente a `'Overdue'`. Lo hará un trabajo diario.
  1199→  1199→
  1200→  1200→#### Paso 1 – Habilitar pg_cron en Supabase
  1201→  1201→En el dashboard de Supabase, ve a `Database > Extensions` y activa `pg_cron`.  
  1202→  1202→(Si no está disponible, usaremos una Edge Function programada).
  1203→  1203→
  1204→  1204→#### Paso 2 – Crear la función que actualiza
  1205→  1205→Ejecuta en el SQL Editor:
  1206→  1206→
  1207→  1207→```sql
  1208→  1208→create or replace function public.auto_mark_overdue_invoices()
  1209→  1209→returns void
  1210→  1210→language sql
  1211→  1211→as $$
  1212→  1212→  update public.invoices
  1213→  1213→  set status = 'Overdue'
  1214→  1214→  where status in ('Draft', 'Sent')
  1215→  1215→    and due_date < current_date;
  1216→  1216→$$;
  1217→  1217→```

  1259→  1259→## 2. Auto‑regulación y auto‑recuperación ante errores
  1260→  1260→
  1261→  1261→La “auto‑regulación” significa que el sistema se mantiene estable y se repara solo. Lo conseguimos con:
  1262→  1262→
  1263→  1263→- **Restricciones en la base de datos** (CHECK, NOT NULL, claves foráneas) → Ya las tienes.
  1264→  1264→- **Triggers que corrigen inconsistencias** (ej. recalcular total de factura si se modifica un item).
  1265→  1265→- **Reintentos automáticos en el frontend**.
  1266→  1266→- **Reconexión automática de suscripciones realtime**.
  1267→  1267→
  1268→  1268→### 2.1 Trigger para mantener la integridad del total de la factura
  1269→  1269→
  1270→  1270→Aunque `invoice_items.amount` es una columna generada, podríamos necesitar que `invoices.total_amount` se actualice si se añade, modifica o elimina una línea. Para eso creamos un trigger:
  1271→  1271→
  1272→  1272→```sql
  1273→  1273→-- Función que recalcula el total de una factura
  1274→  1274→create or replace function public.update_invoice_total()
  1275→  1275→returns trigger
  1276→  1276→language plpgsql
  1277→  1277→as $$
  1278→  1278→begin
  1279→  1279→  if TG_OP = 'DELETE' then
  1280→  1280→    update public.invoices
  1281→  1281→    set total_amount = (select coalesce(sum(amount),0) from public.invoice_items where invoice_id = OLD.invoice_id)
  1282→  1282→    where id = OLD.invoice_id;
  1283→  1283→  else
  1284→  1284→    update public.invoices
  1285→  1285→    set total_amount = (select coalesce(sum(amount),0) from public.invoice_items where invoice_id = NEW.invoice_id)
  1286→  1286→    where id = NEW.invoice_id;
  1287→  1287→  end if;
  1288→  1288→  return null;
  1289→  1289→end;
  1290→  1290→$$;
  1291→  1291→
  1292→  1292→-- Asignar el trigger a la tabla invoice_items
  1293→  1293→create trigger invoice_items_total_update
  1294→  1294→after insert or update or delete on public.invoice_items
  1295→  1295→for each row execute function public.update_invoice_total();
  1296→  1296→```
  1297→  1297→
  1298→  1298→Así, si alguien manipula las líneas directamente, el total se ajusta solo.

  1300→  1300→### 2.2 Auto‑recuperación en el frontend (reintentos y reconexión)
  1301→  1301→
  1302→  1302→**Reintentos en llamadas a la API**  
  1303→  1303→Puedes envolver tus funciones de `lib/api.ts` con una estrategia simple de reintento:
  1304→  1304→
  1305→  1305→```typescript
  1306→  1306→// lib/apiUtils.ts
  1307→  1307→export async function withRetry<T>(fn: () => Promise<T>, retries = 3): Promise<T> {
  1308→  1308→  for (let i = 0; i < retries; i++) {
  1309→  1309→    try {
  1310→  1310→      return await fn();
  1311→  1311→    } catch (error) {
  1312→  1312→      if (i === retries - 1) throw error;
  1313→  1313→      console.warn(`Retry ${i+1} after error:`, error);
  1314→  1314→      await new Promise(r => setTimeout(r, 1000 * Math.pow(2, i))); // backoff
  1315→  1315→    }
  1316→  1316→  }
  1317→  1317→  throw new Error('Unreachable');
  1318→  1318→}
  1319→  1319→```
  1320→  1320→
  1321→  1321→Luego en `api.ts`:
  1322→  1322→```typescript
  1323→  1323→import { withRetry } from './apiUtils';
  1324→  1324→
  1325→  1325→export async function getClientProjects(clientId: string) {
  1326→  1326→  return withRetry(() => supabase.from('projects').select('*').eq('client_id', clientId).order(...));
  1327→  1327→}
  1328→  1328→```
  1329→  1329→
  1330→  1330→**Reconexión automática de canales realtime**  
  1331→  1331→El cliente de Supabase reintenta la conexión automáticamente, pero puedes añadir un listener para reiniciar el canal si falla:
  1332→  1332→
  1333→  1333→```typescript
  1334→  1334→const channel = supabase.channel('room', {
  1335→  1335→  config: { broadcast: { ack: true } },
  1336→  1336→}).subscribe((status) => {
  1337→  1337→  if (status === 'CLOSED' || status === 'CHANNEL_ERROR') {
  1338→  1338→    console.log('Canal cerrado, reconectando...');
  1339→  1339→    setTimeout(() => channel.subscribe(), 2000);

  1348→  1348→## 4. Orquestación con Edge Functions programadas (alternativa sin pg_cron)
  1349→  1349→
  1350→  1350→Si tu plan de Supabase no incluye pg_cron, crea una Edge Function que se ejecute periódicamente mediante un **Cron Job de Supabase** (disponible en el dashboard en `Edge Functions > Cron Jobs`).
  1351→  1351→
  1352→  1352→Ejemplo de función `update-overdue`:
  1353→  1353→
  1354→  1354→```typescript
  1355→  1355→// supabase/functions/update-overdue/index.ts
  1356→  1356→import { serve } from 'https://deno.land/std@0.168.0/http/server.ts';
  1357→  1357→import { createClient } from 'https://esm.sh/@supabase/supabase-js@2';
  1358→  1358→
  1359→  1359→serve(async (_req) => {
  1360→  1360→  const supabase = createClient(Deno.env.get('SUPABASE_URL')!, Deno.env.get('SUPABASE_SERVICE_ROLE_KEY')!);
  1361→  1361→  const { error } = await supabase
  1362→  1362→    .from('invoices')
  1363→  1363→    .update({ status: 'Overdue' })
  1364→  1364→    .in('status', ['Draft', 'Sent'])
  1365→  1365→    .lt('due_date', new Date().toISOString().split('T')[0]);
  1366→  1366→  if (error) return new Response(JSON.stringify(error), { status: 500 });
  1367→  1367→  return new Response(JSON.stringify({ success: true }), { headers: { 'Content-Type': 'application/json' } });
  1368→  1368→});
  1369→  1369→```
