   189→   189→  1189→  1189→## 1. Procesos en segundo plano (Background Jobs)
   190→   190→  1190→  1190→
   191→   191→  1191→  1191→Supabase ofrece dos caminos limpios:
   192→   192→  1192→  1192→
   193→   193→  1193→  1193→- **pg_cron** (extensión de PostgreSQL) → Ideal para tareas recurrentes simples (cada minuto, hora, día).

   196→   196→  1196→  1196→### 1.1 Actualización automática de facturas vencidas
   197→   197→  1197→  1197→
   198→   198→  1198→  1198→Queremos que las facturas con `status != 'Paid'` y `due_date < today()` pasen automáticamente a `'Overdue'`. Lo hará un trabajo diario.
   199→   199→  1199→  1199→
   200→   200→  1200→  1200→#### Paso 1 – Habilitar pg_cron en Supabase
   201→   201→  1201→  1201→En el dashboard de Supabase, ve a `Database > Extensions` y activa `pg_cron`.  
   202→   202→  1202→  1202→(Si no está disponible, usaremos una Edge Function programada).
   203→   203→  1203→  1203→
   204→   204→  1204→  1204→#### Paso 2 – Crear la función que actualiza
   205→   205→  1205→  1205→Ejecuta en el SQL Editor:
   206→   206→  1206→  1206→
   207→   207→  1207→  1207→```sql
   208→   208→  1208→  1208→create or replace function public.auto_mark_overdue_invoices()
   209→   209→  1209→  1209→returns void
   210→   210→  1210→  1210→language sql
   211→   211→  1211→  1211→as $$
   212→   212→  1212→  1212→  update public.invoices
   213→   213→  1213→  1213→  set status = 'Overdue'
   214→   214→  1214→  1214→  where status in ('Draft', 'Sent')
   215→   215→  1215→  1215→    and due_date < current_date;
   216→   216→  1216→  1216→$$;
   217→   217→  1217→  1217→```
   218→   218→  1218→  1218→
   219→   219→  1219→  1219→#### Paso 3 – Programar la tarea
   220→   220→  1220→  1220→```sql

   259→   259→  1259→  1259→## 2. Auto‑regulación y auto‑recuperación ante errores
   260→   260→  1260→  1260→
   261→   261→  1261→  1261→La “auto‑regulación” significa que el sistema se mantiene estable y se repara solo. Lo conseguimos con:
   262→   262→  1262→  1262→
   263→   263→  1263→  1263→- **Restricciones en la base de datos** (CHECK, NOT NULL, claves foráneas) → Ya las tienes.
   264→   264→  1264→  1264→- **Triggers que corrigen inconsistencias** (ej. recalcular total de factura si se modifica un item).
   265→   265→  1265→  1265→- **Reintentos automáticos en el frontend**.
   266→   266→  1266→  1266→- **Reconexión automática de suscripciones realtime**.
   267→   267→  1267→  1267→
   268→   268→  1268→  1268→### 2.1 Trigger para mantener la integridad del total de la factura
   269→   269→  1269→  1269→
   270→   270→  1270→  1270→Aunque `invoice_items.amount` es una columna generada, podríamos necesitar que `invoices.total_amount` se actualice si se añade, modifica o elimina una línea. Para eso creamos un trigger:
   271→   271→  1271→  1271→
   272→   272→  1272→  1272→```sql
   273→   273→  1273→  1273→-- Función que recalcula el total de una factura
   274→   274→  1274→  1274→create or replace function public.update_invoice_total()
   275→   275→  1275→  1275→returns trigger
   276→   276→  1276→  1276→language plpgsql
   277→   277→  1277→  1277→as $$
   278→   278→  1278→  1278→begin
   279→   279→  1279→  1279→  if TG_OP = 'DELETE' then
   280→   280→  1280→  1280→    update public.invoices
   281→   281→  1281→  1281→    set total_amount = (select coalesce(sum(amount),0) from public.invoice_items where invoice_id = OLD.invoice_id)
   282→   282→  1282→  1282→    where id = OLD.invoice_id;
   283→   283→  1283→  1283→  else
   284→   284→  1284→  1284→    update public.invoices
   285→   285→  1285→  1285→    set total_amount = (select coalesce(sum(amount),0) from public.invoice_items where invoice_id = NEW.invoice_id)
   286→   286→  1286→  1286→    where id = NEW.invoice_id;
   287→   287→  1287→  1287→  end if;
   288→   288→  1288→  1288→  return null;
   289→   289→  1289→  1289→end;
   290→   290→  1290→  1290→$$;
   291→   291→  1291→  1291→
   292→   292→  1292→  1292→-- Asignar el trigger a la tabla invoice_items
   293→   293→  1293→  1293→create trigger invoice_items_total_update
   294→   294→  1294→  1294→after insert or update or delete on public.invoice_items
   295→   295→  1295→  1295→for each row execute function public.update_invoice_total();
   296→   296→  1296→  1296→```
   297→   297→  1297→  1297→
   298→   298→  1298→  1298→Así, si alguien manipula las líneas directamente, el total se ajusta solo.
   299→   299→  1299→  1299→
   300→   300→  1300→  1300→### 2.2 Auto‑recuperación en el frontend (reintentos y reconexión)
   301→   301→  1301→  1301→
   302→   302→  1302→  1302→**Reintentos en llamadas a la API**  
   303→   303→  1303→  1303→Puedes envolver tus funciones de `lib/api.ts` con una estrategia simple de reintento:
   304→   304→  1304→  1304→
   305→   305→  1305→  1305→```typescript
   306→   306→  1306→  1306→// lib/apiUtils.ts
   307→   307→  1307→  1307→export async function withRetry<T>(fn: () => Promise<T>, retries = 3): Promise<T> {
   308→   308→  1308→  1308→  for (let i = 0; i < retries; i++) {
   309→   309→  1309→  1309→    try {
   310→   310→  1310→  1310→      return await fn();
   311→   311→  1311→  1311→    } catch (error) {
   312→   312→  1312→  1312→      if (i === retries - 1) throw error;
   313→   313→  1313→  1313→      console.warn(`Retry ${i+1} after error:`, error);
   314→   314→  1314→  1314→      await new Promise(r => setTimeout(r, 1000 * Math.pow(2, i))); // backoff
   315→   315→  1315→  1315→    }
   316→   316→  1316→  1316→  }

   349→   349→  1349→  1349→
   350→   350→  1350→  1350→Si tu plan de Supabase no incluye pg_cron, crea una Edge Function que se ejecute periódicamente mediante un **Cron Job de Supabase** (disponible en el dashboard en `Edge Functions > Cron Jobs`).
   351→   351→  1351→  1351→
   352→   352→  1352→  1352→Ejemplo de función `update-overdue`:
   353→   353→  1353→  1353→
   354→   354→  1354→  1354→```typescript
   355→   355→  1355→  1355→// supabase/functions/update-overdue/index.ts
   356→   356→  1356→  1356→import { serve } from 'https://deno.land/std@0.168.0/http/server.ts';
   357→   357→  1357→  1357→import { createClient } from 'https://esm.sh/@supabase/supabase-js@2';
   358→   358→  1358→  1358→
   359→   359→  1359→  1359→serve(async (_req) => {
   360→   360→  1360→  1360→  const supabase = createClient(Deno.env.get('SUPABASE_URL')!, Deno.env.get('SUPABASE_SERVICE_ROLE_KEY')!);
   361→   361→  1361→  1361→  const { error } = await supabase
   362→   362→  1362→  1362→    .from('invoices')
   363→   363→  1363→  1363→    .update({ status: 'Overdue' })
   364→   364→  1364→  1364→    .in('status', ['Draft', 'Sent'])
   365→   365→  1365→  1365→    .lt('due_date', new Date().toISOString().split('T')[0]);
   366→   366→  1366→  1366→  if (error) return new Response(JSON.stringify(error), { status: 500 });
   367→   367→  1367→  1367→  return new Response(JSON.stringify({ success: true }), { headers: { 'Content-Type': 'application/json' } });
   368→   368→  1368→  1368→});
   369→   369→  1369→  1369→```
